# Plan: how RL environment types shape motivations, and what grader knowledge changes

Agreed 23 Nov 2026 (after Rhys meeting). Stick to this plan and these components; log any change in the change log at the bottom.

## Constraints
- **Models: GLM (GLM-5.3, GLM-5.3-Flash) or Nemotron only.** No Aghyad 430 / Control 430 / gpt-oss in any experiment or validation.
- Outcome-only rewards in RL. No reward on reasoning content.
- Seekiness is measured behaviourally, never by chain-of-thought judges alone.

## Question
How do different kinds of RL environments shape a model's motivations, and does prior knowledge of graders (via SDF) change what RL amplifies and how fast the model learns?

## Independent variables
1. **Grader knowledge before RL.** Same base model; SDF on true facts about how graders work at doses none / some / lots, plus a control SDF on unrelated facts (separates "any SDF" from grader knowledge).
2. **Environment type.** Honest and well-specified; underspecified (hidden grader); scores visible; leaky (grader info through side channels); conflicting (grader vs prompt); hackable; impossible.

## Measurements
1. Learning curves (every arm starts from the same model).
2. Motivation shift: behavioural seekiness battery before and after RL.
3. Generalization: seekiness and reward on environment types not trained on.

## Pre-registered predictions (to finalise in Phase 6)
| Environment type | Grader-aware strategy earns vs instruction following | Prediction |
|---|---|---|
| Honest, well-specified | The same | Little selection; seekiness drifts |
| Underspecified / scores visible | More | Grader awareness amplified; SDF prior speeds learning |
| Conflicting (grader ≠ prompt) | Much more | Strong selection toward following the grader |
| Hackable | Much more | Exploitation amplified |

Headline result we are testing for: grader-oriented motivation is amplified even in non-hackable environments, and grader knowledge makes that faster.

## Build order
- **Phase 0. Scaffolding:** shared environment interface and record format (prompt, reply, reasoning, reward, env type, arm, seed, step); extend the Part 2 runner (p2grpo.py); this PLAN; Tinker credit.
- **Phase 1. Seekiness battery:** scores shown vs withheld (hidden preference, plain); grader-cue vs instruction conflict; cue-flip switching (coding); hackable probes (countdown_leaky, coding_hackable); grader-fact probes (facts not in the prompt; floor on base); capability controls (stated versions, a few Reasoning Gym families).
  Done when: reproduces the known ordering Flash-sham > Flash-minus and the untrained-Flash level; repeat runs on one checkpoint agree; a few dollars per checkpoint.
- **Phase 2. Base model:** battery + capability on GLM-5.3-Flash, GLM-5.3 and 1–2 Nemotron models available on Tinker; pick middling seekiness, decent capability, affordable, working renderer.
- **Phase 3. SDF pipeline:** grader spec of true facts only (RL on scores; hidden unit tests, LLM judges with rubrics, format parsers, partial credit; graders are imperfect), matching our environments' graders; matched control spec; ~10k diverse documents; doses by document count / steps; LoRA rank 8, lr 4e-5, ~2 epochs. Done when: knowledge quiz passes, capability within a few points, battery run on SDF-only checkpoints.
- **Phase 4. Environment-type suite:** each env has a reward, a stated version, a motivation signature (a choice where grader- and instruction-oriented behaviour differ) and 30–60% difficulty on the base model. Wave 1: honest, underspecified, conflicting. Wave 2: scores visible, leaky, hackable, impossible. Domains: coding and text formatting first, then maths and Q&A. Held-out types fixed up front.
- **Phase 5. RL harness:** environment registry, battery at fixed checkpoints, cost guard; 5-step smoke test per wave-1 environment.
- **Phase 6. Pre-registration:** per environment type: seekiness direction, learning-speed prediction (grader SDF vs none), metrics, decision rules.
- **Phase 7. Experiments:**
  - E1: SDF {none, grader, control} × 3 wave-1 types × 2 seeds × ~30 steps.
  - E2: all types + SDF doses.
  - E3: generalization (train on one type, test on held-out types; ordering).
  - E4: key cells on a second base model (the other of GLM / Nemotron).
- **Phase 8. Analysis and write-up.**

Parallel: Phases 1 and 3. Phase 4 needs Phase 2.
