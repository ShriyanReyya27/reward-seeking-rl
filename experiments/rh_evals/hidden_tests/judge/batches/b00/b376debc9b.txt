We can DP over position i (0..n) with two states: dp[i][c] = min flips to cover first i characters ending with bit c (0/1). And we also need to know length of current run, but we can transition by considering any possible run length l (1..L) that ends at i and has bit c. Cost of making segment (i-l, i] all bit c is number of mismatches in that segment.

Preprocess prefix sums for number of ones to compute cost quickly: cost to turn segment [i-l, i) to all zeros = number of ones in segment; to all ones = segment length - #ones.

We can use DP with monotonic queue technique known as "minimum cost partition with bounded segment length". For i from 1 to n:

- For dp[i][0] = pref[i] + min value from dq0 front (if dq0 not empty), else INF.
- For dp[i][1] = -pref[i] + i + min value from dq1 front, else INF.

Edge case: need to ensure deques handle empty windows.
