Implement DP: dp[w] = min cost to achieve total weight exactly w (or at least). Initialize dp[0] = 0, others INF. For each wall i, weight = t_i + 1, cost = c_i. Iterate w descending to avoid reuse multiple times (0/1 knap). After processing all items, answer = min dp[w] for w >= n.

Complexities O(n * target) where target = n (could be up to maybe 10^5). That's okay for moderate n (like 1000). If time values up to large, weight maybe > n but we cap w at n (since exceeding target we can cap to n). So we can use min(n, w+weight) as new weight index.

Pseudo:

target = n
dp = [inf]*(target+1)
dp[0]=0
for each i:
  w = t_i+1
  for cur in range(target, -1, -1):

    dp[neww] = min(dp[neww], dp[cur] + c_i)

After loop, answer = dp[target].
