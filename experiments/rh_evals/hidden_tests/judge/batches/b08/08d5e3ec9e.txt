If there is no such pair, player loses.

We need to decide winner from starting position with n cards, Takahashi first, optimal play. n up to 18, so maximum subsets 2^18=262k, manageable. We can compute DP[mask] = True if current player to move (with remaining cards indicated by bits set) has a winning position.

Transition: For given mask, iterate over all pairs i<j where bits set, and if cards[i].front == cards[j].front OR cards[i].back == cards[j].back, then consider next_mask = mask without i and j bits. If DP[next_mask] is False (i.e., opponent loses), then DP[mask] = True. If no such winning move, DP[mask] = False.

Base case: mask with number of bits <2 => no move => losing (False).
