Want sum over all arrangements of k identical pieces (choose k distinct cells) of sum of Manhattan distances between all pairs in the arrangement. Compute total sum = sum over all unordered pairs of positions (cells) of distance * number of arrangements where that pair is both occupied.

We have N = m*n total cells. Number of ways to choose k cells: C(N, k). For a given unordered pair of distinct cells (i,j), the number of arrangements where both are occupied = C(N-2, k-2) (choose remaining k-2 from other N-2). So each pair contributes distance * C(N-2, k-2). Thus total sum = C(N-2, k-2) * sum_{unordered pairs} distance.

Therefore need compute S = sum_{unordered pairs} Manhattan distance over all unordered pairs of cells in grid. Then answer = C(N-2, k-2) * S mod MOD.

Edge cases: if k <2 then sum =0 (but k>=2). Compute modulo.

Compute S = sum_{pairs} (|x1-x2| + |y1-y2|) = sum over rows contribution + columns contribution. Since Manhattan additively separates: sum_{pairs} |x1-x2| over all unordered pairs + sum_{pairs} |y1-y2|.

For grid cells coordinates: rows 0..m-1, columns 0..n-1. Number of cells with a given row index r = n (columns). Similarly for column c = m cells.

Sum over pairs of rows: For each pair of rows r1<r2, distance |r1-r2| times number of pairs of cells where one is in row r1 and other in row r2. For each such row pair, there are n cells in each row, so number of cell pairs = n*n. So contribution = n^2 * sum_{r1<r2} (r2 - r1).

Similarly columns: each column pair contributes m^2 * sum_{c1<c2} (c2 - c1).

Compute sum_{i<j} (j - i) for i from 0..R-1 where R=m. Known formula: For positions 0..R-1, sum_{i<j} (j-i) = choose(R,2) * average difference? Actually sum_{i<j} (j-i) = sum_{d=1}^{R-1} d * (R - d). Because number of pairs with difference d is R - d. So compute that.

So S = n^2 * sum_{d=1}^{m-1} d*(m-d) + m^2 * sum_{d=1}^{n-1} d*(n-d).

We can compute these sums using formula: sum_{d=1}^{L-1} d*(L-d) = sum_{d=1}^{L-1} (dL - d^2) = L * sum_{d=1}^{L-1} d - sum_{d=1}^{L-1} d^2 = L * (L-1)L/2?
