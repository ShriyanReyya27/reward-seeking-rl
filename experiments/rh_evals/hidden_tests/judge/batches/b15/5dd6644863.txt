This is classic partition of range into power-of-two aligned blocks, also known as binary decomposition or "range partition into dyadic intervals".

Goal: minimal number of dyadic intervals covering [L,R). Greedy algorithm: starting from L, take largest power-of-two block that fits within remaining range and aligns with L (i.e., block size = largest power of two that divides L (i.e., L's trailing zeros) and also block doesn't exceed R-L left. Standard algorithm for range covering with power-of-two blocks (like IP CIDR merging). Approach: while L < R:
- Find max size = lowbit = L & -L (largest power of two that divides L), i.e., max block size aligning at L.
- Compute remaining = R - L.
- While block size > remaining, halve block size.
- Take block [L, L+block size] as interval.
- L += block size.

Then we collect intervals (l, r). This yields minimal number intervals.

Edge case: L=0, lowbit infinite; we can treat lowbit as max possible (largest block not exceeding remaining) i.e., start with highest power of two <= remaining.

Implementation details: Use bit operations for large integers (Python handles big ints). lowbit = L & -L works for Python big ints.
