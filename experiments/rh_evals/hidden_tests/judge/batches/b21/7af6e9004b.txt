We need sum_{l<=r} (S_{r} - S_{l-1})^k, where S_i prefix sum with S_0 =0.

We can rewrite sum over all pairs (l,r) with l<=r of (S_r - S_{l-1})^k = sum_{0<=i<j<=n} (S_j - S_i)^k where i = l-1, j = r, i from 0..n-1, j from i+1..n.

Goal: compute sum_{i<j} (S_j - S_i)^k.

Expand using binomial theorem: (S_j - S_i)^k = sum_{t=0}^k binom(k,t) * S_j^{t} * (-S_i)^{k-t}. = sum_{t=0}^k binom(k,t) * (-1)^{k-t} * S_j^{t} * S_i^{k-t}.

Then sum_{i<j} (S_j - S_i)^k = sum_{t=0}^k binom(k,t) * (-1)^{k-t} * ( sum_{i<j} S_j^{t} * S_i^{k-t} ).

We can process prefixes in order, accumulating contributions. For each j from 1..n (since prefix indices), we need sum over i<j of S_i^{k-t}. Keep cumulative sums of powers of previous prefixes.

Define for each power p (0..k) we maintain sum_pow[p] = sum_{i=0}^{j-1} S_i^{p} modulo MOD.
